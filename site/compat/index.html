Slicer compatibility

Every night, Form Studio's automation builds each recipe in the CAD kernel at its default values, runs its checks and slices it with the official build of every slicer it supports. Each cell is a real slice: print time and filament come from that slicer's own G-code.

How this is made

The matrix runs on GitHub's standard Linux runners with the slicer versions pinned in the workflow, never opened, with one printer and filament preset per slicer. Times are the slicer's estimates, a simulation, not a measured print.

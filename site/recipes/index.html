Recipe gallery

Parametric families of parts. Each recipe builds a valid solid from typed parameters, attributes every face to a feature and brings its own engineering checks. Agents start from them and change anything; install a community recipe with form recipes install after reading its source.

    Add your recipe

    A community recipe is a folder with three files: recipe.py (or recipe.scad), meta.json and preview.png. Paste it in a recipe issue, or run form recipes submit: it is built, checked and sliced automatically and the issue is answered with pictures. Accepted recipes join the gallery.

    The format Writing a recipe Share or request a recipe

    For tools: index.json lists every recipe with its source URL and SHA-256 (schema version 1).

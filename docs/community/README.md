# Community guides

The guides of the Form Studio Discord server, kept here so they are reviewed like the rest of the documentation. Each file is posted as plain message text in the server's guides forum by `scripts/discord/setup_server.py`, and edited in place when the file changes.

| Guide | For |
|---|---|
| [Getting started](getting-started.md) | Installing on macOS, Windows and Linux, the first start and a first design |
| [Agents and MCP](agents-and-mcp.md) | Claude Code, Codex and any other MCP agent, model APIs and local models |
| [Mesh to editable CAD](mesh-to-cad.md) | Turning STL, OBJ and 3MF files into CAD you can change |
| [Game assets](game-assets.md) | LODs, UVs, baked maps and collision for Unreal, Unity, Godot and glTF |
| [Optional engines and programs](optional-engines.md) | CAD-Recode, CADFit, CoACD, the CADEvolve corpus, Blender, FreeCAD, OpenSCAD and slicers |
| [3D printing (optional)](printing.md) | Slicers, printers, fit and print simulation |
| [Troubleshooting and reporting bugs](troubleshooting.md) | Fixing common problems, asking for help and writing a bug report |
| [Contributing](contributing.md) | Where contributions go, the development setup and pull requests |

Writing rules, so a guide reads the same on GitHub and in Discord: headings (`#`, `##`, `###`), lists, bold, code blocks and links with full addresses. No tables, pictures or HTML inside a guide. A channel is written as `#help`; the server setup turns it into a link to the channel.

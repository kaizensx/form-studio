### FAIL

None outstanding. Defects found and fixed during verification: coupon measurements were counted as physical validation of a part (caught by `test_08`); per-face tessellation made drafts slow; lead-in faces were mis-attributed at coarse tolerance; the draft panel collapsed in long inspectors; a stray “null” rendered in the Release panel.

One failed call is on record: the first `fable` check ran with the client's full default system prompt, was flagged by that model's safeguards, and cost $0.246 against a $0.25 cap. The studio's own consult path replaces the system prompt; the retry in that form succeeded.
